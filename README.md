# Credit-Card-Transaction-Analytics-and-Fraud-Monitoring-System

## About the Project
I developed a Credit Card Transaction Analytics and Fraud Monitoring System using Python, Streamlit, and MySQL to analyze credit card transactions, identify suspicious activities, detect potential fraud, and monitor fraud alerts.

The main goal of this project is to help monitor transactions, understand transaction patterns, and identify potentially fraudulent activities using transaction details and risk-based rules.

## Problem Statement
Credit card transactions happen every day, and some transactions may involve suspicious activities such as unusually high amounts, repeated transactions, or unexpected transaction locations. Identifying these activities manually can be difficult and time-consuming.

This project helps analyze transaction data, flag potentially suspicious transactions, assign risk levels, and maintain fraud alerts for monitoring.

## Key Features
- **Transaction Analytics:** Analyze transaction records and transaction patterns.
- **Fraud Detection:** Identify potentially suspicious transactions using detection rules.
- **Risk Assessment:** Assign risk scores and risk levels to flagged transactions.
- **Fraud Alert Monitoring:** View and manage fraud alerts.
- **MySQL Database:** Store and manage customer, account, transaction, and fraud alert data.
- **Interactive Dashboard:** Use Streamlit to display transaction information and analytics.

## Technologies Used
- Python
- Streamlit
- MySQL
- SQL
- Pandas (if used in the implementation)

## Database Tables
- `customers` – Stores customer information.
- `accounts` – Stores account details.
- `transactions` – Stores transaction records.
- `fraud_alerts` – Stores detected fraud alerts and risk information.

## Project Workflow
1. Store customer, account, and transaction data in MySQL.
2. Retrieve transaction records using Python.
3. Analyze transactions and apply fraud detection rules.
4. Assign risk scores and risk levels to suspicious transactions.
5. Display transaction analytics and fraud alerts through the Streamlit dashboard.
